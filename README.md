# acceso-a-datos-xml

El siguiente proyecto procesa un fichero XML similar al siguiente en un fichero CSV

```xml
<list>
    <Persona>
        <Nombre>Ana Pérez</Nombre>
        <AnyoNacimiento>1995</AnyoNacimiento>
        <Ciudad>Madrid</Ciudad>
    </Persona>
    <Persona>
        <Nombre>Carlos Gómez</Nombre>
        <AnyoNacimiento>1988</AnyoNacimiento>
        <Ciudad>Barcelona</Ciudad>
    </Persona>
    <Persona>
        <Nombre>Lucía Fernández</Nombre>
        <AnyoNacimiento>2001</AnyoNacimiento>
        <Ciudad>Valencia</Ciudad>
    </Persona>
</list>
```
